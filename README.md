## Installation

Follow the [installation guide](https://docs.n8n.io/integrations/community-nodes/installation/) in the n8n community nodes documentation.

## Requirements

The hc:VISION services are installed on the customer's own infrastructure. There is no public demo instance, so you need access to an existing installation.
